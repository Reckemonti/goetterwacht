# Götterwacht

Nordisches Wellen-Überlebensspiel im Browser. Eine einzige HTML-Datei, keine Installation, kein Server.

## Spielen

- **Direkt:** `index.html` herunterladen und im Browser öffnen (PC oder Handy).
- **Online:** über GitHub Pages, sobald aktiviert (Settings → Pages → Branch `main`, Ordner `/`).

Steuerung: `W` `A` `S` `D` oder Pfeiltasten, `Esc` für Pause. Handy: Daumen aufs Feld und ziehen.

## Inhalt

- 3 Götter mit eigenem Fokus: **Donar** (Donnerschlag, Donnerhämmer, Blitze), **Ulfr** (Axtschwung, kreisende Äxte, Wurfäxte, Blutrausch), **Skadi** (Speerstoss, Eisspeere, Wurfspeere)
- Gemeinsame Fähigkeiten: Walküren-Schar, Walküren-Zirkel, Rollende Fässer, Runenkreis, Göttlicher Einschlag (Ulti)
- Verschmelzungen, Kombos, Stufe-5-Erwachen
- Schicksalswurf alle 9 Stufen (Segen und Flüche)
- Wellen mit wachsender Fäulnis, Elite-Gegnern, Wolfshorden und mehreren Bossen
- Runenschmiede (dauerhafte Upgrades)

## Spielstand

Der Fortschritt wird automatisch im Browser gespeichert. Mit **⬇ Spielstand speichern** auf dem Startbildschirm lädst du eine JSON-Datei herunter (Runen, Runenschmiede, Rekorde). Mit **⬆ Spielstand laden** stellst du sie wieder her, auch auf einem anderen Gerät.

## Dateien

| Datei | Zweck |
| --- | --- |
| `index.html` | Spielbare Version (eigenständig, für Browser und GitHub Pages) |
| `quelle-claude-artifact.html` | Gleicher Code als Seiteninhalt für die claude.ai-Version |
| `STATUS.md` | Stand und offene Punkte |
